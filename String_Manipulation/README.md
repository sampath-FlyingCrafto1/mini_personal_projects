**StringManipulator Class**

This Python class provides a set of methods for manipulating strings. 

**Features:**

- **Concatenation:** Concatenates the given string with another string.
- **Length:** Returns the length of the string.
- **Slicing:** Extracts a substring from the given start and end indices.
- **Repetition:** Repeats the string a specified number of times.
- **Case Conversion:** Converts the string to uppercase or lowercase.
- **Stripping:** Removes leading and trailing whitespace from the string.
- **Splitting:** Splits the string into a list of substrings based on a separator.
- **Formatting:** Formats the string using positional arguments.
- **Interpolation:** Formats the string using keyword arguments.
