# Text-to-Speech GUI with Python

This Python script provides a user-friendly graphical interface for text-to-speech functionality.

**Features:**

- Uses the `pyttsx3` library to convert text to speech and play it back through the system's default audio output.
- Employs the `tkinter` library to create a simple GUI with a label, textbox, and button.
- Allows users to enter text in the textbox and click the button to initiate speech synthesis.

**Requirements:**

- `pyttsx3` library: `pip install pyttsx3`
- `tkinter` library (included in most Python installations)

**How to Run:**

1. Save the code as a Python file (e.g., `text_to_speech_gui.py`).
2. Open a terminal or command prompt and navigate to the directory where you saved the file.
3. Run the script using the following command:

   ```bash
   python text_to_speech_gui.py
